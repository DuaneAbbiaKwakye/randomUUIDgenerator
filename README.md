This project creates 9 objects with random UUIDs and prints each UUID into a .txt file. 
It can also generate a  32 character long password from those UUIDs by scrambling up the characters and randomly setting some to Uppercase.
The .txt here is just an example of what will be outputted- you don't need to download that for this to work.

You can choose between 4 Options:
  1. Generate UUIDs only
  2. Generate passwords only (This will not create/overwrite a .txt file)
  3. Generate both UUIDs and a password
  4. Close program

Just so you know, the program checks if theres .txt called "UUIDs.txt" deletes and replaces with a new one if you've already created one.
This is just a small practice project. Nothing complex.
